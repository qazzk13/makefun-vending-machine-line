The bounty wanted one pickup line, the way a vending machine would actually say it to somebody walking past. Mine is the machine that's been stuck in a hallway all night with a bag of chips hanging halfway out of its coil, half flirting, half asking for help, and honestly not sure itself which one it means more.

`main.ts` writes that single line to `/output/entry.txt`, checks it fits the rules first (one sentence, 200 characters at most, no line breaks), and reads the file back to make sure what landed on disk is the line it meant to write. Fixed string, no network, no clock, same output every run.

## Run it

```sh
node main.ts
```
